# SentinelX — ML Evaluation

> ML models and evaluation metrics will be implemented in Phase 8.

## Planned Models

| Model | Purpose | Metrics |
|-------|---------|---------|
| Behavioral Anomaly Detection | Detect unusual user file access patterns | Precision, Recall, F1, AUC-ROC |
| Risk Prediction | Predict risk score for file operations | MAE, RMSE, R² |
| Threat Classification | Classify security event severity | Accuracy, Confusion Matrix |

## Evaluation Methodology (Planned)

1. Train/test split with temporal ordering
2. Cross-validation for model selection
3. Benchmark against rule-based baseline
4. False positive rate analysis
5. Latency profiling for real-time inference
